# 美术使用指南

## 第一次启动

Windows 下载 Release 中的 portable EXE，双击运行。macOS 下载 arm64 DMG；当前包未签名且尚无 Mac 真机验证，内置 x86_64 binvox 需要 Rosetta 2。打开右上角设置检查 binvox 状态；若内置程序不可用，可选择自己下载的兼容 binvox。

## 制作资产

1. 在建模工具中确认轴向、轴心与尺寸，1 单位按 1 米处理。导出 GLB，或 OBJ、MTL 和贴图。OBJ 的配套文件一起选择。
2. 点击“导入模型”，检查源模型预览。先从 64 或 128 档开始，选择 32、64、128、256、512 之一并转换。
3. 在“模型”模块使用增加、删除、涂色和吸色，修改的是资产库预制体。若只改场景中的单一物件，保持在“关卡”模块使用笔刷，首次实际修改会自动隔离。
4. 需要改变分辨率时，使用“从源模型重新转换”。重新转换会重新生成体素，应先保存工程版本。

## 编辑关卡

点击资产添加实例；在场景树中选择物件，使用移动、旋转、缩放或属性中的数值输入。Shift 多选，分组/解组管理层级。隐藏、锁定和网格吸附可辅助编辑。F 聚焦全部。示例关卡用于熟悉操作。

## 颜色与编辑范围

右上角 Help、桌面菜单 Help → 使用教程，或 F1 均可打开完整分章节教程，可在创作时直接查阅。右侧历史颜色保存最近确认选用、吸取和涂色的 16 种颜色，重开桌面版后保留；拖动色盘时不记录中间色。色盘左右调整饱和度，上下调整明暗度；HSV 滑块和数值框分别控制色相（0–360°）、饱和度（0–100%）、明暗度（0–100%）。也可输入六位 HEX 色值。

模型模块修改原预制体，并同步到尚未独立修改的实例。关卡模块的涂色、增删体素只影响当前物件，自动保留原预制体。切回模型模块仍显示原预制体；已经独立修改的场景物件不会再被原预制体覆盖。位置、旋转、缩放在关卡模块操作。

例如两棵相同的树：在模型模块修改树预制体，两棵一起改变；在关卡模块给第一棵涂色，第二棵不变。复制已经独立修改的树后，继续在关卡编辑其中一棵仍不会影响另一棵。

关卡笔刷模式下点击另一物件会先选择它，再次点击才编辑。点击移动、旋转或缩放工具恢复普通选择。场景独立模型随工程保存和导出，资产库只列出可复用的预制体。

## 保存与交付

“保存”得到 .vxlproj，可在方境重新打开，保留源模型、体素颜色和场景节点。自动草稿仅用于本机恢复，不能替代正式工程包。

“导出天工”菜单提供天工 0.4.19 交付 ZIP、可编辑工程包和通用 GLB 三个独立选项。建议同时保存工程包和天工交付 ZIP。把交付 ZIP 交给开发同学，按 [天工导入指南](TIANGONG.md) 继续。天工内可改关卡布局并添加玩法；逐格体素编辑仍在方境完成，不支持反向同步。

## 性能建议

优先复用资产实例，避免把每个实例都转成独立资产。512 档会显著增加体素数据；颜色杂乱或表面破碎的模型即使体素数较少，也可能生成很多三角面。遇到预算提示可在“设置 → 容量与性能”调整对应预算，或按资产拆分。暂未实现相机驱动的分区流式加载和 LOD。实测范围见 [性能记录](PERFORMANCE.md)。

从 Alpha.5 起，工程包按资产和源文件分别存储。源模型压缩保留，重新转换时自动解压；可以打开旧版工程，新工程请使用 Alpha.5 或更新版本。分辨率只控制单个资产的体素网格，不决定整个场景的物件数量或空间范围。

## 大场景容量设置

设置中的所有容量预算都可修改，填 0 表示不设应用上限。默认值如下：

| 项目 | 默认值 |
| --- | --- |
| 工程/导出文件及工程展开数据 | 2048 MiB |
| 单次导入或重载的源模型与贴图总量 | 2048 MiB |
| 传给 binvox 的几何文本 | 512 MiB |
| 单个资产占用体素 | 500 万 |
| 单个资产合并后的表面 | 100 万 |
| 源模型三角面数 | 不设应用上限 |
| 转换自动停止时限 | 不限，可手动取消 |

资产种类、源模型数量和场景物件数量不再设固定数量上限。预算不等于承诺可用容量：提高预算后仍取决于电脑内存、显存及模型结构。单资产转换网格仍最高 512³；这不是整个场景的大小限制。当前工程包使用标准 ZIP，最多 65,535 个文件条目、整体需低于 4 GiB；每个资产和源文件分别占一个条目。接近格式上限时需要拆分工程。

移动或重命名物件时，自动保存只更新场景信息，未修改的模型和源文件不重复写入。隐藏分组可以释放仅被该分组使用的显示网格；重新显示时重新生成。源模型仍保存在工程内，工程没有变成外链文件。

从 Alpha.6 起，关卡笔刷修改会自动保存独立物件与原预制体的关联。请用 Alpha.6 或更新版本继续编辑，以保留相同的模块编辑规则。

## 逐面添加方块

选择“增加”，点击已有方块的某个面，即在该面外侧放置一个相邻方块。一次只放 1 格，点空白不会放置，不覆盖已有方块。原网格边缘会自动扩展（每轴最多 512 格），已有模型位置和方块尺寸保持不变。关卡模块仍只修改当前物件，模型模块仍修改预制体。
