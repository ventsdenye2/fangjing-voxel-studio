# 美术使用指南

## 第一次启动

Windows 下载 Release 中的 portable EXE，双击运行。macOS 下载 arm64 DMG；当前包未签名且尚无 Mac 真机验证，内置 x86_64 binvox 需要 Rosetta 2。打开右上角设置检查 binvox 状态；若内置程序不可用，可选择自己下载的兼容 binvox。

## 制作资产

1. 在建模工具中确认轴向、轴心与尺寸，1 单位按 1 米处理。导出 GLB，或 OBJ、MTL 和贴图。OBJ 的配套文件一起选择。
2. 点击“导入模型”，检查源模型预览。先从 64 或 128 档开始，选择 32、64、128、256、512 之一并转换。
3. 在“模型”模式中使用增加、删除、涂色和吸色。多个实例共享同一资产；只修改其中一个时，先点“创建独立副本”。
4. 需要改变分辨率时，使用“从源模型重新转换”。重新转换会重新生成体素，应先保存工程版本。

## 编辑关卡

点击资产添加实例；在场景树中选择物件，使用移动、旋转、缩放或属性中的数值输入。Shift 多选，分组/解组管理层级。隐藏、锁定和网格吸附可辅助编辑。F 聚焦全部。示例关卡用于熟悉操作。

## 保存与交付

“保存”得到 .vxlproj，可在方境重新打开，保留源模型、体素颜色和场景节点。自动草稿仅用于本机恢复，不能替代正式工程包。

“导出天工”得到交付 ZIP：包含天工 0.4.19 Pack、通用 GLB 和编辑工程。把整个 ZIP 交给开发同学，按 [天工导入指南](TIANGONG.md) 继续。天工内可改关卡布局并添加玩法；逐格体素编辑仍在方境完成，不支持反向同步。

## 性能建议

优先复用资产实例，避免把每个实例都转成独立资产。512 档会显著增加体素数据；颜色杂乱或表面破碎的模型即使体素数较少，也可能生成很多三角面。遇到预算提示请降低档位。首版适合小中型关卡，尚未实现分区加载和 LOD。实测范围见 [性能记录](PERFORMANCE.md)。

从 Alpha.4 起源模型在工程内压缩保存，重新转换时自动解压，旧工程仍可打开。使用新工程时请配套 Alpha.4 或更新版本；旧版不识别压缩源文件。模型超过 300 万三角面或精简几何超过 128 MiB 时需要先减面。分辨率只控制输出体素网格，不会减少输入模型面数。
