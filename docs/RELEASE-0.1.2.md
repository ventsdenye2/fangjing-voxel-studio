# 0.1.2

修复三维框选时松开鼠标后镜头仍跟随移动的问题：选框和镜头控制器统一接收画布事件，框选时关闭模型变换控制器和左键镜头平移。左键拖动彩色轴调整选框，右键旋转视角，滚轮缩放。

更新直接面向最新正式版本。下载和安装前重新检查；已缓存中间版本时，下载最新版后再安装，相同版本缓存仍可复用。已下载状态也能重新检查，检查失败不会安装旧缓存。发布流程明确将正式版本标记为 GitHub Latest。

验证：Playwright 使用真实鼠标事件复现旧绑定松手后继续平移；修复后拖动选框能修改范围，模型位置与镜头不变，松手后不再移动。覆盖更新跨版本、缓存复用、离线失败的单元测试通过。浏览器验证环境为 Chromium、1200×800；未验证 macOS 实机安装。
