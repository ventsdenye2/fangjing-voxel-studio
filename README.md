# 方境 · Voxel Studio

方境是一款面向美术的本地体素编辑器，可以将 GLB、OBJ 等常见格式的 3D 模型转换为体素模型。转换后，你可以继续增删体素、调整颜色、摆放场景，再导出模型和关卡，导入天工引擎继续制作游戏。

目前直接支持 GLB，以及带 MTL 材质和贴图的 OBJ。转换在桌面版本机运行，支持 Windows 和 macOS。

[下载安装包](https://github.com/ventsdenye2/fangjing-voxel-studio/releases) · [美术使用指南](docs/ARTIST-GUIDE.md)

当前为 Alpha 预发布版本。Windows 的模型转换、编辑、保存和天工导入流程已验证；macOS 尚未完成真机验证，持续帧率与峰值内存也仍待测试。具体进展见 [开发记录](docs/DEVELOPMENT.md)。

## 工作流

1. **导入模型。** 选择 GLB 文件，或将 OBJ、MTL 和贴图一起导入，检查模型预览。
2. **转换为体素。** 使用 binvox 转换，可选 32、64、128、256、512 档分辨率。
3. **继续编辑。** 增加或删除体素，用涂色、吸色工具修整颜色；也可以把多个资产放进同一个关卡。
4. **保存与导出。** 保存为可再次打开的工程，或点击“导出天工”，生成包含通用 GLB、天工 0.4.19 Pack 和编辑工程的 ZIP。

场景编辑支持选择、多选、移动、旋转、等比缩放、复制、分组、隐藏、锁定和网格吸附。工程会保留源模型、体素颜色和独立场景节点，方便后续修改。

导出的 Pack 可导入天工引擎，保留场景层级和物件标识，在天工里继续调整关卡布局、添加玩法。逐格修改体素仍需在方境中完成，目前不支持从天工反向同步。导入步骤见 [天工导入](docs/TIANGONG.md)。

资产和场景物件数量不设固定上限。处理大模型时，可以在设置中调整容量预算，填 0 取消对应的应用限制。512 是单个资产的体素网格档位，不是整个场景的大小上限；实际容量仍取决于内存、显存和数据结构。

## 开发

Windows 和 macOS 共用一套 Electron + React + Three.js 源码。开发需要 Node.js 22、npm。

```sh
npm ci
npm run desktop:dev
npm test
npm run build
```

网页版 `npm run dev` 支持编辑、项目和场景导出；调用本地 binvox 转换模型需要使用桌面版。
